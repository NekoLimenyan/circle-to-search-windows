## ✨ Особливості та дизайн

- **Жива градієнтна аура Google:** плавне переливчасте світіння по периметру екрана (`#4285F4` → `#9B72CB` → `#EA4335` → `#FBBC05` → `#34A853`) при активації.
- **Плаваючий тулбар One UI:** капсульна панель інструментів із 2x-згладжуванням, плавною анімацією виїзду та пружинним слайдером.
- **Ефект Spotlight:** м'яке затемнення фону зі збереженням 100% чіткості та яскравості виділеної зони.
- **Розумне обведення (Ласо):** згладжування тремтіння миші за алгоритмом Чайкіна, 4x антиаліасинг маски та природний розмитий контекстний фон замість білих кутів.
- **Пам'ять останнього режиму:** обраний інструмент автоматично зберігається між викликами та перезавантаженнями ПК.
- **One UI Toast-сповіщення:** ненав'язливі спливаючі підказки знизу екрана замість системних вікон зі звуком помилки.
- **Multi-Monitor & Per-Monitor High-DPI:** точна робота без зміщення координат на кількох моніторах і дисплеях із масштабуванням 125%, 150% та 4K.

## 🛠 Режими роботи

| Клавіша | Режим | Опис |
|:---:|:---|:---|
| <kbd>1</kbd> | **▢ Прямокутник** | Класичне виділення області для миттєвого візуального пошуку в **Google Lens**. |
| <kbd>2</kbd> | **〰 Обведення (Ласо)** | Вільне обведення об'єкта довільної форми зі згладжуванням контуру та пошуком у **Google Lens**. |
| <kbd>3</kbd> | **⧉ Швидке копіювання** | Миттєве вирізання фрагмента екрана одразу в буфер обміну без відкриття браузера. |
| <kbd>4</kbd> | **T Розпізнавання (OCR)** | Локальне розпізнавання тексту (українська, англійська) через системний **Windows OCR** із копіюванням у буфер. |

## ⌨ Керування

| Комбінація / Дія | Призначення |
|:---|:---|
| <kbd>Alt</kbd> + <kbd>Q</kbd> | Активувати або закрити оверлей виділення. |

## 🚀 Швидкий старт

### 1. Клонування репозиторію

```bash
git clone https://github.com/NekoLimenyan/circle-to-search-windows.git
cd circle-to-search-windows
```

### 2. Встановлення в один клік

1. Запустіть **`setup.bat`**.
2. Скрипт автоматично:
   - встановить необхідні залежності (`Pillow`, `keyboard`, `winocr`);
   - згенерує іконку лупи у кольорах Google;
   - створить ярлики на **Робочому столі** та в меню **Пуск**;
   - за бажанням додасть програму в **Автозавантаження Windows**.
3. Натисніть <kbd>Alt</kbd> + <kbd>Q</kbd> у будь-якому місці екрана.

> **Порада:** повторний запуск ярлика **Circle to Search** коректно завершує фоновий процес — ярлик працює як зручний перемикач **УВІМК / ВИМК**.

## 🗂 Структура проєкту

```text
Circle to Search/
├── circle_to_search.pyw      # Точка входу, фонова служба та глобальний хоткей
├── setup.bat                 # Автоматичне налаштування, ярлики та автозапуск
├── requirements.txt          # Список залежностей Python
└── app/
    ├── config.py             # Налаштування, палітра Google та збереження стану
    ├── win_api.py            # Windows API (High-DPI, буфер обміну, монітори, PID)
    ├── graphics.py           # Градієнтна аура, згладжування Чайкіна та 4x маска
    ├── actions.py            # Google Lens, системний OCR та One UI Toast
    ├── overlay.py            # Повноекранний оверлей Spotlight і плаваючий тулбар
    ├── icon_gen.py           # Процедурний генератор .ico іконки лупи
    └── shortcut.py           # Створення ярликів Windows Shell (з підтримкою OneDrive)
```
