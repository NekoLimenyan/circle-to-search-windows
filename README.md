# 🔍 Circle to Search for Windows

![Python](https://img.shields.io/badge/Python-3.10%2B-blue?logo=python)
![Platform](https://img.shields.io/badge/Platform-Windows%2010%20%7C%2011-0078D6?logo=windows)
![License](https://img.shields.io/badge/License-MIT-green)

Настольный аналог функции **Circle to Search** из Android для Windows 10/11 с неоморфным оверлеем, векторными иконками и нативным системным OCR.

---

## ✨ Возможности
* **Анимированный оверлей:** мягкое затемнение экрана и динамическое градиентное свечение по периметру дисплея.
* **Минималистичный тулбар:** неоморфная панель с плавной пружинной анимацией переключения режимов.
* **3 режима захвата:**
  * ▢ **Прямоугольник** — классическое выделение нужного участка.
  * 〰 **Ласо (Lasso)** — свободное обведение объекта произвольной формы с автоматической изоляцией фона на белую маску.
  * **T (OCR)** — мгновенное распознавание украинского, русского и английского текста с копированием в буфер обмена без открытия браузера.
* **Google Lens:** автоматическая отправка скриншота в поиск через браузер по умолчанию.
* **Per-Monitor High-DPI:** точные координаты без смещения на экранах с масштабированием 125%, 150% и 4K.
