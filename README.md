# 🔍 Circle to Search for Windows

![Python](https://img.shields.io/badge/Python-3.10%2B-blue?logo=python)
![Platform](https://img.shields.io/badge/Platform-Windows%2010%20%7C%2011-0078D6?logo=windows)

Настольный аналог функции **Circle to Search** из Android для Windows 10/11 с неоморфным оверлеем, векторными иконками и нативным системным OCR[cite: 25].

---

## ✨ Возможности

* **Анимированный оверлей:** мягкое затемнение экрана и динамическое градиентное свечение по периметру дисплея[cite: 25].
* **Минималистичный тулбар:** неоморфная панель с плавной пружинной анимацией переключения режимов[cite: 25].
* **3 режима захвата:**
  * ▢ **Прямоугольник** — классическое выделение нужного участка[cite: 25].
  * 〰 **Ласо (Lasso)** — свободное обведение объекта произвольной формы с автоматической изоляцией фона на белую маску[cite: 25].
  * **T (OCR)** — мгновенное распознавание украинского, русского и английского текста с копированием в буфер обмена без открытия браузера[cite: 25].
* **Google Lens:** автоматическая отправка скриншота в поиск через браузер по умолчанию[cite: 25].
* **Per-Monitor High-DPI:** точные координаты без смещения на экранах с масштабированием 125%, 150% и 4K[cite: 25].

## 🚀 Быстрый старт

### 1. Клонирование репозитория

```bash
git clone [https://github.com/NekoLimenyan/circle-to-search-windows.git](https://github.com/NekoLimenyan/circle-to-search-windows.git)
cd circle-to-search-windows

2. Установка и запуск
Запустите файл setup.bat двойным кликом.

Скрипт установит библиотеки (pillow, keyboard, winocr) и создаст ярлык Circle to Search на Рабочем столе.

Запустите ярлык для активации фоновой службы.

Повторный запуск ярлыка останавливает службу (работает как тумблер ВКЛ / ВЫКЛ).

⌨ Управление
Клавиша / Действие	Назначение
Alt + Q	Активировать оверлей Circle to Search
Esc	Отмена / закрытие оверлея
ЛКМ	Выделение области или выбор инструмента в тулбаре
